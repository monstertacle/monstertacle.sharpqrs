1. Inspect the run, its jobs and its artefacts with the GitHub CLI or REST API, and read the `publish` job log.
2. Before expiry, download artefact `verification-ubuntu-24.04` of the run, read `run.json` and hash `packages/*.nupkg`.
3. Download the served packages from
   `https://api.nuget.org/v3-flatcontainer/<lower-case id>/0.2.0-alpha.1/<lower-case id>.0.2.0-alpha.1.nupkg` and hash them.
4. Extract canonical and served packages and compare their entries; only `.signature.p7s` may differ.
5. Run `dotnet nuget verify --all <served package>`.
6. Compute the Base64 SHA-512 of each canonical package and compare it with a consumer lock file.

Downloaded packages only need to be hashed, extracted and verified; nothing from them has to be executed.
